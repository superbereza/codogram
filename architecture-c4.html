Level 3: Component Diagram (Bot internals)
handlers/
Command routers: /start, /new_chat, /finish, /settings. Thin layer, delegates to services.
middleware/
Auth (AdminMiddleware), admin rights check, setup blocker.
services/
Business logic: StartFlowService, LaunchService, BranchService, etc.
domain/
Models, FSM states, validators. Pure data, no deps.
core/session_manager
ProjectState, ThreadInfo. 40+ fields. File locking persistence.
core/coordinator
HistoryWatcher. Polls jsonl, binds sessions, detects changes.
telegram/queue
Rate-limited FIFO queue. Chunking, markdown, retries.
telegram/keyboards
Pure keyboard builders. 16 files, stateless.
claude/screen
20+ regex patterns. Parses tmux output for prompts, status.
claude/poller
6 processors: permissions, ask_user, thinking, suggestions, stuck, compact.
claude/history_watcher
Async jsonl watcher. 5 display modes.
claude/session_finder
Incremental jsonl reader with caching.
tmux/session
TmuxSession. Send keys, capture pane. Timing-sensitive.
tmux/launcher
Project init, git ops, tmux creation.
git/worktree
Worktree CRUD, merge, push. Subprocess.
git/utils
Branch validation, sanitization.
