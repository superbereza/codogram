# DM Onboarding + Dashboard

## Overview

Онбординг для новых пользователей при /start в директ бота + дашборд для просмотра всех подключённых проектов.

## Онбординг

### Триггер
Пользователь отправляет `/start` в DM бота (первый раз или без активных проектов).

### Флоу

```
/start в DM
    ↓
1. Приветствие (отдельное сообщение)
    ↓
2. Карусель ценностей (редактируемое сообщение с кнопками ← →)
   - Слайд 1: Мобильность — запускай задачи с телефона, работай откуда угодно
   - Слайд 2: Асинхронность — запустил → занялся своим → получил уведомление
   - Слайд 3: Команда — настрой один раз, работай с коллегами
    ↓
3. Валидация окружения
   ├─ ❌ Проблема → "Вернись на сервер, исправь X" + мини-инструкция
   │                 Кнопка [Проверить снова]
   └─ ✅ Всё ок → далее
    ↓
4. CTA: "Создай группу, добавь меня админом. Бот подхватит автоматически"
    ↓
🏁 Онбординг завершён
```

### Валидация окружения

**Критичные (блокируют):**
- `BASE_DIR` указан в конфиге (не пустой)
- `BASE_DIR` существует на диске
- `claude` доступен в PATH
- `tmux` доступен

**Варнинги (показываем, не блокируем):**
- `git config user.name/email` не настроен
- `gh auth status` не авторизован
- SSH ключи отсутствуют

### Тон

Прагматичный, без маркетингового хайпа. Референс: https://granda.org/en/2026/01/02/claude-code-on-the-go/

## Пуш при добавлении в чат

Когда бота добавляют в любой чат (независимо от онбординга), отправляем уведомление в DM админа:

```
Меня добавили в «Chat Name»
Чат: (ссылка — TBD)
Создатель: @username
```

## Дашборд

### Команда
`/dash` — доступна только в DM, только для админов.

### Формат

```
📊 Проекты

1. codogram
   📁 /home/user/dev/codogram
   👤 Создатель: @superbereza
   👥 3 участника
   🤖 2 сессии Claude

2. my-app
   📁 /home/user/dev/my-app
   👤 Создатель: @teammate
   👥 5 участников
   💤 не активен

Всего: 2 проекта, 2 активных сессии

[Обновить]
```

### Поля
- Название чата (заголовок)
- Директория проекта (BASE_DIR/project)
- Создатель чата (@username)
- Количество участников
- Статус Claude сессий (N сессий / не активен)
- Кнопка "Обновить"

## DM режимы

1. **Онбординг** — для новых пользователей, показывается один раз
2. **Дашборд** — для опытных, вызывается через `/dash`
3. **Уведомления** — пуши о добавлении в чаты

DM отвечает только админам (ADMIN_IDS из .env).
