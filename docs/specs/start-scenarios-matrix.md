# Start Scenarios Matrix

Полная матрица сценариев для команд /start, /session_new, /restart_session, /session_close.

## Пользователь
- За ноутом (локально)
- На сервере (удалённо)

## Действие пользователя
- Начинает проект с нуля
- Продолжает проект
- Создаёт новую сессию (ветку)
- Закрывает сессию
- Перезапускает сессию

## Тип чата
- Обычная группа (без топиков)
- Мультигруппа (с топиками)
- Личка с ботом

## Откуда пишет (для мультигруппы)
- General (thread_id=None)
- Конкретный топик (thread_id=123)

---

## Свойства среды

### 1. Директория
- Не существует
- Существует, но пустая
- Существует с файлами

### 2. Git (релевантно для "начинает/продолжает проект")
- Нет git нигде
- Есть локальный git (без remote)
- Есть локальный git + remote
- Есть только в облаке (нужен clone)

### 3. Tmux сессии в директории
- 0 tmux
- 1 tmux
- Несколько tmux

### 4. Характеристики tmux
- Название по конвенции / не по конвенции
- Claude запущен внутри / не запущен
- Claude ready / Claude busy

### 5. Конфиг бота
- Проект есть в конфиге / нет
- chat_id привязан / не привязан
- session_id сохранён / не сохранён

### 6. Треды (для мультигруппы)
- Тред зарегистрирован с именем
- Тред зарегистрирован как "pending"
- Тред не зарегистрирован (топик создан вручную)
- Топика вообще нет

### 7. Состояние бота
- Poller/Watcher запущены
- Не запущены (бот перезапустился)
