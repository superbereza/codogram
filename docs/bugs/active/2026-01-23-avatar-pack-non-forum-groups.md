# Avatar pack создаётся в обычных группах

## Описание
Avatar emoji pack предлагается создать при setup в обычных супергруппах без топиков (форумов).

## Ожидаемое поведение
Avatar pack должен предлагаться только в группах с включёнными топиками (forums), т.к. эмодзи используются как иконки топиков.

## Фактическое поведение
При setup в супергруппе без форума показывается сообщение "Gift unlocked - Avatar pack" с предложением персонализировать топики.

## Шаги воспроизведения
1. Создать супергруппу (megagroup) без форума
2. Добавить бота
3. Пройти setup flow до конца
4. Появляется сообщение про Avatar pack

## Причина
В коде не проверяется `chat.is_forum` перед показом предложения создать avatar pack.

## Приоритет
Low - косметический баг, функционально ничего не ломает.
