Core Modules (External Integration)

permission_poller.py
src/codogram/permission_poller.py
580 LOC
Polls tmux screen for permission prompts. State machine with debounce, crash detection, auto-accept.
State Machine
  • IDLE → detect → DEBOUNCING
  • DEBOUNCING → 0.5s → SHOWING
  • SHOWING → button click → IDLE
Features
  • Crash detection (panic, SIGSEGV)
  • Auto-accept mode
  • Thinking status spinner
  • Input suggestions
Complex async state machine. Screen parsing is fragile (Claude UI changes). Many edge cases with timing.
telegram_queue.py
src/codogram/telegram_queue.py
510 LOC
Rate-limited FIFO message queue. Per-chat workers, retry logic, chunking.
Batch Types
  • OutgoingBatch - new messages
  • EditBatch - edit existing
  • KeyboardBatch - inline keyboard
  • DeleteBatch - delete message
Complex async queue with per-chat workers. Rate limiting logic. Message ordering guarantees.
screen.py
src/codogram/screen.py
437 LOC
